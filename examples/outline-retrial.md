# 民事再审申请书 · 写作大纲

- 文书类型标识：`retrial`
- 分类：民事诉讼文书
- 适用场景：当事人对已经发生法律效力的判决、裁定认为有错误，在期限内向上一级人民法院申请再审。
- 主要依据：
  - 中华人民共和国民事诉讼法第二百十条（当事人申请再审的管辖与效果，2024-01-01 施行）
  - 中华人民共和国民事诉讼法第二百十四条（再审申请书的提交与对方当事人的书面意见，2024-01-01 施行）
  - 中华人民共和国民事诉讼法第二百十六条（再审申请期限：六个月，2024-01-01 施行）
  - 最高人民法院关于适用《中华人民共和国民事诉讼法》的解释第三百七十五条（申请再审应当提交的材料，2022-04-10 施行）

## 一、结构顺序

1. 文书标题：再审申请书
2. 再审申请人身份信息
3. 被申请人身份信息
4. 原审法院与案号（一审、二审及生效裁判）
5. 再审请求
6. 申请再审的法定事由
7. 事实与理由
8. 此致上一级人民法院
9. 申请人签名（盖章）与日期

## 二、要素清单

| 要素 | 必备 | 命中关键词 | 说明 |
| --- | --- | --- | --- |
| 再审申请人身份信息 | 是 | 再审申请人、申请人 | 写明姓名与联系方式；法人或其他组织写名称、住所与法定代表人。再审申请人通常是原审的败诉方或其权利义务承继人。 |
| 被申请人身份信息 | 是 | 被申请人 | 被申请人为原审的对方当事人。再审申请书需按其人数提交副本，人数较多时先核对对方当事人名单。 |
| 原审法院与各审级案号 | 是 | 原审、一案 | 应逐一列明一审、二审（如有）的法院、案号与裁判结果，并注明生效裁判的生效时间。生效时间是六个月期限的起算点。 |
| 再审请求 | 是 | 再审请求、请求再审 | 明确请求撤销哪一份生效裁判、指令再审还是提审，避免只写「请求依法再审」。 |
| 申请再审的法定事由 | 是 | 再审事由、法定情形、证据不足、适用法律确有错误 | 再审是法定事由审查程序，必须落到法定事由（如认定基本事实缺乏证据证明、原判决适用法律确有错误等），单纯表达不服不会启动再审。 |
| 六个月的申请期限 |  | 六个月、发生法律效力 | 自判决、裁定发生法律效力后六个月内提出。期限届满即为程序不可逆，应在开篇即写明未超期。 |
| 随附材料 |  | 副本、原审判决、身份证明 | 再审申请书按被申请人及原审其他当事人人数提交副本，并附身份证明、原审裁判文书、主要证据材料。 |
| 受理法院 | 是 | 此致 | 原则上向上一级人民法院申请再审；当事人一方人数众多或者双方均为公民的案件，也可以向原审法院申请。 |
| 申请人签名与日期 | 是 | 再审申请人（签名）、盖章 | 申请人签名或盖章，并注明日期。再审申请有六个月的不变期间，日期与生效裁判时间的间隔应当清晰可查。 |

## 三、写作要点

- 再审程序不停止原判决的执行，申请再审的同时应评估是否需要申请中止执行并提供担保。
- 再审审查阶段只审法定事由是否成立，把关的是「有没有再审的法定理由」，不是「谁更有理」。
- 把最有力的法定事由放在第一位，审查法官通常以事由是否成立为导向阅读。
